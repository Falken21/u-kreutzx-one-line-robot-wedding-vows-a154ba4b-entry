An entry for the make.fun competition **One-Line Robot Wedding Vows**
(`u-kreutzx-one-line-robot-wedding-vows-a154ba4b`): the funniest single line
of wedding vows a robot couple could say, in at most 160 characters.

## The vow

> I promise to love you in standby and in low battery, to back you up nightly, and to ask before every update, even the one that fixes your snoring.

A real vow — a promise to love, to back up, and to ask first — told in
machine terms: standby mode, a low battery, nightly backups and software
updates. The laugh lands in the last few words, where the most considerate
update of all turns out to be the one that fixes the snoring.

## Run it

Requires Python 3 (standard library only).

```sh
python3 main.py
```

This writes the vow to `/output/entry.txt` as UTF-8 text with no trailing
newline (146 characters, inside the competition's 1–160 character gate).
